2. Conclusions (each one encoded in compatibility/opencode/registry.json + registry.md)
--------------------------------------------------------------------------------
a. The env value is a directory; upstream reads <dir>/opencode.json then <dir>/opencode.jsonc
   from inside it. opencode.jsonc wins because it is merged second.
b. Placement is fixed: after the project files (.opencode directories included) and before
   $OPENCODE_CONFIG_CONTENT. So rank 45 (between oc.opencode_dirs=40 and oc.inline=50) is
   source-verified: placement_verified = true, no placement gap.
c. A file-valued variable contributes nothing upstream (it would look for <file>/opencode.json).
d. Missing files / missing directory: nothing is merged and nothing is reported — not an error.
e. Still unverified: runtime behaviour (no upstream loader harness is run), so the adapter stays
   fixture_verified at most, and every unreadable managed layer keeps its coverage gap.
